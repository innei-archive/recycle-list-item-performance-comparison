# Batch Performance Comparison

This project compares the performance of batching techniques in React.

## Features

- Recycle mode: Fixed pool of components that get updated
- Window recreate mode: Create new components for each visible item
- Profiler: Track the performance of the components
- Dynamic pool size: Dynamically adjust the pool size based on the scroll position
- Ramp-up: Gradually increase the pool size over time
- Memory usage: Track the memory usage of the components
